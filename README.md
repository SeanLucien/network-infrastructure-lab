# Virtual Network Infrastructure & Troubleshooting Lab

## Overview

This project is a hands-on virtual networking lab designed to demonstrate practical networking configuration, troubleshooting, and diagnostic skills.

The lab will use virtual machines to simulate a small network environment and intentionally introduce configuration problems that must be identified and resolved.

## Objectives

* Configure IPv4 addressing and subnetting
* Configure DHCP and DNS
* Configure default gateways and routing
* Configure and troubleshoot firewall rules
* Configure SSH connectivity
* Test network connectivity using command-line tools
* Capture and analyze network traffic with Wireshark
* Practice a structured network troubleshooting methodology
* Document configurations, problems, solutions, and findings

## Planned Environment

* VirtualBox
* Windows virtual machines
* Linux virtual machines
* Windows Server
* Wireshark
* Command-line networking utilities

## Network Architecture

The network topology and addressing scheme will be documented as the lab is built.

## Troubleshooting Scenarios

Planned troubleshooting scenarios include:

* Incorrect IP configuration
* Incorrect default gateway
* DNS resolution failure
* Blocked network ports
* Firewall configuration problems
* SSH connectivity failure
* General connectivity issues
